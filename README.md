# RyunaRia

Original PSP homebrew action RPG project.

## Current target

- Platform: PSP / PPSSPP
- Genre: isometric action RPG
- Core pillars: exploration, combat, grinding, equipment, adaptive monsters
- Distribution goal: a single `.iso` release artifact
- Early builds prioritize a playable prototype over content volume

## Build

The project is built in GitHub Actions using the PSPDEV/PSPSDK toolchain.

The repository intentionally keeps generated binaries and build output out of source control.
